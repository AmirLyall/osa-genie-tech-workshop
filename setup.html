Setup for OSA's Databricks workspace administrators

Attendees each build their own Genie Agent on a shared set of synthetic P-card tables, then create one metric view of their own. Before the session, make sure of four things.

1. The workshop tables

If the osa_pcard_review schema already exists in your workspace, there's nothing to do. Otherwise, run osa_genie_workshop_setup.py once (import it, set catalog, Run all on serverless). It creates the six tables with descriptions.

2. Access for the attendees' group

  • USE CATALOG on the catalog, and USE SCHEMA and SELECT on osa_pcard_review.
  • The Databricks SQL entitlement, so they can create Genie Agents.
  • Can use on a pro or serverless SQL warehouse.
  • A schema each person can create a view in, such as their ad-hoc schema, for their metric view (USE SCHEMA and CREATE TABLE on it).
  • Permission to run a notebook on serverless compute, for the optional benchmark loader.

3. Genie Workbench

Genie Workbench is a Databricks App. Install it with its notebook installer:

  1. Clone the repo into a Databricks Git folder and open notebooks/install.py.
  2. Attach serverless compute (environment v5) and set the widgets: app_name, catalog, warehouse_id, and lakebase_mode (create, existing or skip).
  3. Run the notebook from the top. It creates the app, a schema for the optimizer, and a job that runs Auto-Optimize.
  4. Give the attendees' group Can use on the app.
Prerequisites: Databricks Apps enabled, Unity AI Gateway available in the workspace's region, a SQL warehouse, and permission to create a schema. Installing usually needs workspace-admin-level rights. Lakebase is optional, but without it scan history and sessions are kept in memory only.

4. A quick check

Sign in as an attendee-like account, create an agent from the six tables, and run load_benchmarks.py against it. Then open Genie Workbench and run an IQ scan on that agent.

All data is synthetic. Agencies, cardholders, merchants and dollar amounts are all made up for training. Nothing here is an OSA finding.
