Facilitator guide

Before the session
  1. Confirm the administrator checklist on the setup page, including the schema attendees will use for their metric views.
  2. Run the whole flow yourself once: create an agent, load the benchmarks, run a baseline, curate it, re-run, and deploy the bundle. Keep that agent as your demo, so you have finished runs to show if a live run is slow.
  3. Check that attendees can run the Databricks CLI (version 1.3.0 or later) against the workspace, from their laptop or the web terminal.
  4. Hybrid room: share one browser window at a large zoom, and have a second person watch the meeting chat for errors people hit.

If something breaks

If the notebook can't load benchmarks, switch the room to the by-hand tab and have people add the first five. If a metric view fails, check the schema permission and carry on with the other fixes. If the CLI isn't available, deploy the bundle from your screen.
