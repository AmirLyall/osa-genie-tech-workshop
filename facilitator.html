Before the session
  1. Confirm the administrator checklist on the setup page, including the schema attendees will use for their metric views.
  2. Build your own demo agent, load the benchmarks, and run a baseline, so you have a finished run to show if a live run is slow.
  3. Make a second identical agent for Workbench. At 12:00, start Auto-Optimize on it so results are ready to discuss at 12:45.
  4. Hybrid room: share one browser window at a large zoom, and have a second person watch the meeting chat for errors people hit.
