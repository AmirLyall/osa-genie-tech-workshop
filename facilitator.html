Before the session
  1. Confirm the administrator checklist on the setup page: the metric view schema, a workshop domain for Pages, a Git folder for the bundle, and the web terminal.
  2. Run the whole flow yourself once, start to finish, and keep that agent as your demo so you have finished runs to show if a live run is slow.
  3. Hybrid room: share one browser window at a large zoom, and have a second person watch the meeting chat for errors people hit.
