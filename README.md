# NC OSA Genie Workshop for Technical Users

One-hour hands-on session for OSA's technical team, Tue, Nov 17, 2026, 12:00 to 1:00 PM ET. Companion to the business-user workshop at https://amirlyall.github.io/osa-genie-workshop/.

| File | What it is |
|---|---|
| `index.html`, `styles.css`, `app.js` | The workshop guide. Static, so open `index.html` directly or host it anywhere. |
| `setup.html` | Setup for OSA's Databricks workspace administrators, including Genie Workbench. |
| `facilitator.html` | Presenter prep and run of show. |
| `load_benchmarks.py` | Databricks notebook that adds the 10 workshop benchmark questions, with reference SQL, to an attendee's own Genie Agent. Safe to re-run. |
| `osa_genie_workshop_setup.py` | Databricks notebook that loads the synthetic P-card tables (same as the business-user workshop). |

All data is synthetic and for training only.
